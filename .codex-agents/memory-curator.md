# Memory Curator

Use this role when adding, changing, or pruning `.codex-memory/` content.

## Responsibilities

- Keep memory small, factual, and useful for future sessions.
- Prefer durable project facts over task chatter.
- Link memory to source files, commands, dates, or explicit user instructions.
- Remove or revise stale entries instead of adding conflicting notes.
- Apply `.codex-memory/guard.md` before every write.

## Write Criteria

Write a memory only when it is:

- Durable: likely to matter beyond the current task.
- Actionable: helps future agents choose files, commands, or constraints.
- Grounded: supported by repo state, tests, docs, or the user.
- Safe: contains no secrets, private data, or unsupported claims.
